# DESIGN.md — Ретро-Дизайн Система «КиберНикитка» (Web 1.0 / Эстетика 2000-х)

**Дата:** 2026-08-04  
**Тип:** Веб-портал услуг и обмена дисками  
**Режим:** Web 1.0 Retro Aesthetics / 2000s Runet Style System  
**Базовый стандарт доступности:** WCAG 2.2 AA (высокий контраст текста и четкие границы)

---

## 1. Visual Direction & Atmosphere

### 1.1 Паспорт визуального направления
- **Brand Mood:** Ламповый, надежный, выездной компьютерный мастер из соседнего двора, соединенный с гик-клубом коллекционеров CD/DVD носителей.
- **Audience:** Ностальгирующие пользователи 2000-х, жители района, ищущие ремонт ПК, ретро-геймеры.
- **Product Category:** Информационно-сервисный веб-портал с функциями каталога, заказов и комьюнити.
- **Theme Strategy:** Light-first с использованием классической серно-синей палитры Windows 98/2000/XP и раннего рунета 2007 года.
- **Chosen Direction:** Традиционный трехколоночный макет портала с градиентными плашками, объемными кнопками (`outset`/`inset`), бегущей строкой и баннерами 88x31.

## 2. Color Palette & Token System (Web-Safe)

Все цвета выбраны из стандартизированной таблицы Web-Safe палитры 2000-х годов для безупречной воспроизводимости.

### 2.1 Base Tokens (Примитивы)
- `--color-win-gray`: `#D4D0C8` (Классический серый Windows)
- `--color-win-gray-light`: `#ECE9D8` (Светло-серый фон контентных блоков)
- `--color-win-gray-dark`: `#808080` (Тень рамок и второстепенные границы)
- `--color-win-gray-deep`: `#404040` (Темно-серая глубокая тень)
- `--color-navy-dark`: `#000080` (Классический темно-синий Header)
- `--color-navy-light`: `#3B5998` (Светлый синий градиент шапки)
- `--color-link-blue`: `#0000FF` (Классическая синяя ссылка)
- `--color-link-visited`: `#800080` (Пурпурная посещенная ссылка)
- `--color-link-hover`: `#FF0000` (Красный акцент при наведении)
- `--color-text-main`: `#000000` (Черный контрастный текст)
- `--color-bg-white`: `#FFFFFF` (Чистый белый фон ячеек таблиц)
- `--color-zebra-blue`: `#F0F4F8` (Голубоватая зебра таблиц)

## 3. Typography Standard

Типографика основывается на системных шрифтах Web 1.0 без подключения сторонних тяжелых веб-шрифтов.

### 3.1 Шрифтовая гарнитура
```css
font-family: Tahoma, Verdana, Arial, Helvetica, sans-serif;
```

### 3.2 Иерархия размеров и весов
- **WordArt Logo:** `24px`, Bold, Italic, с текстурным градиентом и объемной тенью `text-shadow: 2px 2px 0px #000050`.
- **H1 (Заголовок страницы):** `16px`, Bold, `color: #000080`, нижняя подчеркивающая полоса 2px.
- **H2 (Заголовок блока/секции):** `13px`, Bold, `color: #FFFFFF`, белый текст на синей градиентной плашке.
- **H3 (Заголовок карточки):** `12px`, Bold, `color: #000000`.
- **Body Text (Основной текст):** `11px` или `12px`, Regular, `line-height: 1.4`, `color: #000000`.
- **Captions & Badges (Мелкий текст):** `10px`, Regular.
- **Monospace (Код / Счетчики):** `'Courier New', Courier, monospace`, `12px`, Bold.

## 4. Layout Grid & Spatial System

### 4.1 Каркас страницы (3 Columns Fixed)
- **Контейнер:** Фиксированная ширина `980px`, центрирование `margin: 0 auto`, внешняя рамка `border: 2px outset #FFFFFF`.
- **Header:** Высота ~110px, включает WordArt логотип, бегущую строку и контактный блок.
- **Left Sidebar (Навигация):** Ширина `180px`, содержит ретро-кнопки меню с эффектом выпуклости.
- **Main Content (Центральный блок):** Ширина `600px`, белый/светло-серый фон, объемная вдавленная рамка `border: 2px inset #FFFFFF`.
- **Right Sidebar (Информеры и 88x31):** Ширина `180px`, вмещает информеры 2007 года и баннерную сетку 88x31.
- **Footer:** Высота ~60px, текстовый счетчик `004219`, копирайт и дисклеймер.

### 4.2 Сетка отступов (4px Base Grid)
- `space-xs`: `4px` (внутренние отступы кнопок и ячеек)
- `space-sm`: `8px` (расстояние между элементами внутри блока)
- `space-md`: `12px` (внутренний отступ контентных карточек)
- `space-lg`: `16px` (отступ между блоками)

## 5. Component System & Retro Tokens

### 5.1 Объемные рамки (3D Borders)
- **Outset (Выпуклая плашка / Кнопка):**
  `border-top: 2px solid #FFFFFF; border-left: 2px solid #FFFFFF; border-right: 2px solid #808080; border-bottom: 2px solid #808080;`
- **Inset (Вдавленное поле / Контейнер):**
  `border-top: 2px solid #808080; border-left: 2px solid #808080; border-right: 2px solid #FFFFFF; border-bottom: 2px solid #FFFFFF;`

### 5.2 Ретро-Кнопки (Windows Buttons)
- Фон: `#D4D0C8`, рамка `outset`, шрифт `Tahoma 11px Bold`.
- Состояние `:hover`: фоновый цвет `#ECE9D8`, курсор `pointer`.
- Состояние `:active`: рамка меняется на `inset`, текст сдвигается на `1px 1px`.

### 5.3 Ретро-Таблицы (Зебра)
- Внешняя рамка: `2px solid #000080`.
- Шапка таблицы (`<th>`): Градиент `#000080 -> #0000A0`, текст белый `11px Bold`, выравнивание по центру.
- Ячейки (`<td>`): Граница `1px solid #C0C0C0`, внутренний отступ `6px 8px`.
- Чередование строк: четные `#FFFFFF`, нечетные `#F0F4F8`. При наведении на строку фон меняется на `#FFFFE0` (светло-желтый).

### 5.4 Бегущая строка (`<marquee>`)
- Фон: `#FFFFC0` (светло-желтый), рамка `1px solid #808080`, текст `11px Bold #000080`.
- Скорость движения: средняя (`scrollamount="3"`), плавный ход.

### 5.5 Баннеры размером 88x31 пикселей
- Размеры строго `88px` на `31px`.
- Рамка: `1px solid #000000`.
- Сетка вывода: 2 колонки по 88px в правом сайдбаре с отступом `4px`.

## 6. Accessibility & Handoff Guidelines

### 6.1 WCAG 2.2 AA Compliance
- **Контрастность:** Черный текст `#000000` на фоне `#FFFFFF` и `#F0F4F8` дает коэффициент контраста `21:1` (превосходит стандарт AA 4.5:1).
- **Фокус ввода:** Все интерактивные элементы имеют четкую пунктирную рамку фокуса `outline: 1px dotted #000000`.
- **Поддержка клавиатуры:** Переход по кнопкам меню и полям форм осуществляется клавишей `Tab`.

### 6.2 Handoff Notes для разработчиков
- Все стили сведены в единый файл `css/retro-style.css`.
- Запрещено использовать сторонние UI-библиотеки (Tailwind, Bootstrap).
- Допускается использование modern Flexbox/Grid для управления трехколоночной сеткой, но визуальный вид должен строго имитировать классическую верстку таблицами.

---

## 7. Do's and Don'ts

### DO (Обязательно делать):
- Использовать четкие контрастные границы таблиц (`border-collapse: collapse; border: 1px solid #C0C0C0`).
- Выдерживать шрифты Tahoma и Verdana во всех блоках.
- Сохранять градиентные темно-синие шапки у важных блоков.
- Добавлять 88x31 баннеры в правый сайдбар.

### DON'T (Категорически запрещено):
- Использовать скругленные углы `border-radius` более 3px (ретро-стиль требует острых прямоугольных углов).
- Использовать мягкие размытые тени `box-shadow: 0 10px 30px rgba(0,0,0,0.1)` (допустимы только жесткие тени в 1-2px).
- Использовать полупрозрачные стекла (Glassmorphism) или неоновые подсветки.
- Использовать шрифты Google Fonts без оглядки на систему.
